¿Cómo se gestionan los estilos?

La mejor opción para este proyecto es utilizar una hoja de estilos externa llamada estilos.css.

En cada página HTML se enlaza con la etiqueta <link rel="stylesheet" href="estilos.css">.

Así, todos los archivos comparten el mismo diseño, se evita repetir código CSS y es más fácil cambiar los colores, tamaños y distribución desde un único archivo. También permite separar el contenido HTML de la presentación CSS.
